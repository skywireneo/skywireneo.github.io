# Изображения для раздела "Достижения"

Поместите в эту папку изображения для достижений. В `_data/achievements.json` указаны следующие файлы:

## Статьи (articles)
- `article1-cover.jpg` — Обложка для статьи "Микросервисная архитектура: практический подход"

## Конференции (conferences)
- `conf1-stage.jpg` — Выступление на HighLoad++ 2025
- `conf1-slide.jpg` — Слайд с архитектурной схемой
- `conf2-workshop.jpg` — Воркшоп на DevOps Days 2024

## Другое (other)
- `hackathon-win.jpg` — Награждение на хакатоне AI Solutions

## Требования к изображениям
- Формат: JPG, PNG, WebP
- Рекомендуемое разрешение: 1200×800px или выше
- Размер файла: желательно до 500KB для быстрой загрузки

Если изображения отсутствуют, кнопка галереи не будет отображаться для соответствующего достижения.
